# 考研英语一作文模板

来自用户提供的百度网盘分享（提取码 `iq7m`），已下载为本地原件并接入素材库：

- `【英语一】作文资料使用方法.pdf`：模板使用顺序与套用注意事项。
- `【英语一】万能模板1_大作文.pdf`：英语一大作文万能模板。
- `【英语一】万能模板1_小作文.pdf`：英语一小作文（书信 / 通知）万能模板。
- `【英语一】大作文资料.pdf`：大作文话题、段落与句式素材。
- `【英语一】小作文资料.pdf`：小作文题型与句式素材。

站点只做保存与索引，不改写模板原文；页面上的结构框架与自查清单是本站原创整理，
用于和这些模板对照，不冒充官方范文。

原件为 PDF，通过 `npm run build` 被 `scripts/build-manifest.mjs` 收录（`download-only`），
在「素材库 → 考研 → 作文模板」可下载。
