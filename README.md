# iball的小屋

一个按 GitHub 文件夹自动分组的听力词汇网站，支持 Anki CSV 和 Markdown
表格。仅供个人学习使用，不用于商业用途。

## 添加素材

在 GitHub 仓库中按下面的结构上传文件：

```text
materials/
  四级/
    2022年6月.csv
  六级/
    2022年6月.md
  考研/
    2022年真题.md
  电影/
    摩登家庭/
      S01E01 精选 50.md
      S01E01 完整 100.md
```

规则：

- 第一层文件夹名作为一级分类，例如 `四级`、`六级`、`考研`、`电影`。
- 第二层及以下文件夹名作为二级分组，例如 `电影/摩登家庭`。
- 文件可直接放在一级分类下；文件夹可以暂时为空，网站会保留分类位置。
- 文件名作为素材标题，日期前缀 `2026-09-16-` 会自动移除。
- `.md` 使用 Markdown 表格解析，`.csv` 使用 Anki CSV 解析。
- 上传并提交后，Vercel 会自动执行 `npm run build`，重新生成
  `resources.json` 并部署网站。

Markdown 表格支持这些列名：

```markdown
| # | 词/短语 | 释义 | IPA | 英文原句 | 译句 |
```

Anki CSV 的 `#columns` 需要包含 `Front,Back`。

## 网站功能

- 单账号登录，不提供公开注册。
- 按 GitHub 文件夹展示一级分类和二级目录。
- 素材搜索，以及短语、释义、句子、音标搜索。
- 全部收藏集和按一级分类自动生成的分类收藏集，例如 `四级收藏集`、
  `六级收藏集`、`电影收藏集`。
- 收藏、不会的单词、已掌握标记。
- 释义默认遮挡，可全部显示、全部关闭或单条点开。
- 点击英文例句中的任意单词，可查询并显示该词的中文释义和音标。
- 浏览器直接朗读英文词汇。
- 口语跟读练习，支持浏览器免费识别、自定义 API 和关闭识别。
- 口语练习会显示单词匹配度、漏词和额外词，并把最近记录保存在本机。

单词查询通过 `api/word.js` 请求在线词典并缓存结果，因此点击单词释义时
需要网络连接。

## 口语跟读

进入任意素材后点“口语练习”，或直接点词汇卡片上的“跟读”。练习默认使用
浏览器免费语音识别，建议使用最新版 Chrome 或 Edge，并在地址栏允许麦克风。
识别方式可以在右侧切换：

- `浏览器免费`：使用 Web Speech API，不需要 API Key。
- `自定义 API`：录音后把音频发送到你填写的语音转写接口。
- `关闭识别`：只保留示范朗读、原句和翻译，不上传音频。

自定义 API 使用 OpenAI 兼容的 `multipart/form-data` 转写格式：

```text
POST <接口地址>
file=<录音文件>
model=<模型名称，可选>
language=en
```

接口需要返回 JSON，网站会读取 `text`、`transcript`、`result.text` 或
`data.text`；也支持直接返回纯文本。接口必须允许浏览器跨域访问（CORS），
否则静态网站无法直接调用。API 地址、模型和 Key 只保存在当前浏览器的
`localStorage` 中，并直接发送到所填接口，不会经过本站服务器。

练习记录只保存在当前浏览器，不会跨设备同步。完整自由对话功能若需要服务端
会话、音频保存或付费模型，不在当前静态版本内。

## 登录配置

Vercel 项目需要设置以下 Production 环境变量：

- `APP_USERNAME`
- `APP_PASSWORD`
- `SESSION_SECRET`（至少 32 字节随机字符串）

登录接口位于 `api/auth.js`，使用签名 HttpOnly Cookie 保存会话，不需要额外数据库。

口语练习的交互思路参考了 MIT 许可的
[SpeakHub](https://github.com/yin-yizhen/SpeakHub)。
