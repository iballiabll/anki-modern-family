# iball的小屋

一个按 GitHub 文件夹自动分组的听力词汇网站，支持 Anki CSV 和 Markdown
表格，也支持把 HTML、Word 文件作为在线附件。仅供个人学习使用，不用于
商业用途。

## 添加素材

在 GitHub 仓库中按下面的结构上传文件：

```text
materials/
  0基础/
    Level 1-2/
      零基础词汇讲义Level1-2_词汇表.csv
      零基础词汇讲义Level1-2_词汇表.docx
  四级/
    2022年6月听力/
      CET4-2022年06月听力.md
      CET4-2022年06月听力-手机版.html
  六级/
    2022年6月.md
  考研/
    2022年真题.md
  电影/
    摩登家庭/
      S01E01 精选 50.md
      S01E01 完整 100.md
```

规则：

- 第一层文件夹名作为一级分类，例如 `四级`、`六级`、`考研`、`电影`。
- 第二层及以下文件夹名作为二级分组，例如 `电影/摩登家庭`。
- 文件可直接放在一级分类下；文件夹可以暂时为空，网站会保留分类位置。
- 文件名作为素材标题，日期前缀 `2026-09-16-` 会自动移除。
- `.md` 使用 Markdown 表格解析，`.csv` 使用 Anki CSV 或通用词汇 CSV 解析。
- `.html` 会在新窗口打开，`.docx` 会下载文件；两者不会进入复习卡片队列。
- 上传并提交后，Vercel 会自动执行 `npm run build`，重新生成
  `resources.json` 并部署网站。

Markdown 表格支持这些列名：

```markdown
| # | 词/短语 | 释义 | IPA/音标 | 英文原句 | 译句 |
```

Anki CSV 的 `#columns` 需要包含 `Front,Back`。

通用词汇 CSV 支持以下列名：

```text
序号,单词,音标,词性,中文释义,英文例句,分类,小节
```

## 在 GitHub 网页端自行添加素材

1. 打开仓库的 `materials` 文件夹，进入对应分类；没有分类时可以新建文件夹。
2. 点 `Add file` → `Upload files`，把 `.md`、`.csv`、`.html` 或 `.docx`
   文件拖进去。一级文件夹名就是网站分类，二级文件夹名是小节。
3. 在页面底部填写提交说明，例如 `add new vocabulary`，然后点
   `Commit changes`。
4. Vercel 已连接这个仓库时，会自动运行 `npm run build` 并部署；等待一两分钟
   后刷新网站即可看到新素材。
5. 如果要修改已有文件，点文件名旁的铅笔图标，编辑后再次提交。不要手动编辑
   `resources.json`，构建会从 `materials` 自动生成它。

## 网站功能

- 单账号登录，不提供公开注册。
- 按 GitHub 文件夹展示一级分类和二级目录。
- 素材搜索，以及短语、释义、句子、音标搜索。
- 全部收藏集和按一级分类自动生成的分类收藏集，例如 `四级收藏集`、
  `六级收藏集`、`电影收藏集`。
- 收藏、不会的单词、已掌握标记。
- 释义默认遮挡，可全部显示、全部关闭或单条点开。
- 点击英文例句中的任意单词，可查询并显示该词的中文释义和音标。
- 浏览器直接朗读英文词汇。
- 支持把整个素材库、整个一级分类或分类下的单个二级小节导出为
  Anki CSV。
- 口语练习支持“素材跟读”“情景对话”和“自由对话”三种模式。
- 情景对话内置 12 个本地场景，每个场景 3 轮，可输入英文或使用麦克风
  回答：咖啡馆点单、酒店入住、求职面试、街头问路、医院看诊、朋友闲聊、
  机场值机、商店退换货、租房看房，以及雅思口语 Part 1、Part 2、Part 3
  练习。所有场景默认全部可选，没有解锁条件或前置任务。
- 自由对话提供美式英语聊天陪练，英文回复下方附中文翻译，并在每轮回答后
  给出语法、词汇、表达纠错和雅思练习建议，可自动朗读美音。
- 三种口语模式都支持浏览器免费识别、自定义 API 和关闭识别。
- 口语练习会显示单词匹配度、漏词和额外词，并把最近记录保存在本机。
- 情景对话反馈采用低压教练式引导：先肯定已表达内容，每次最多提示
  2 个补全点，并给出一个明确的下一步练习任务。

单词查询通过 `api/word.js` 请求在线词典并缓存结果，因此点击单词释义时
需要网络连接。

## 口语跟读

进入任意素材后点“口语练习”，或直接点词汇卡片上的“跟读”。练习默认使用
浏览器免费语音识别，建议使用最新版 Chrome 或 Edge，并在地址栏允许麦克风。
示范朗读会自动优先选择浏览器提供的 `en-US` 自然声线，也可以切换自然女声、
自然男声或设备默认声线；情景对话会按角色调整语气、音高和语速。朗读完全在
浏览器本地完成，不调用付费 API，也不会把练习文本上传到第三方服务。
识别方式可以在右侧切换：

- `浏览器免费`：使用 Web Speech API，不需要 API Key。
- `自定义 API`：录音后把音频发送到你填写的语音转写接口。
- `关闭识别`：只保留示范朗读、原句和翻译，不上传音频。

自定义 API 的模型名称既可以直接输入，也可以从 `v4flash`、`v4pro` 等
预设项中选择；具体模型是否支持转写，由所填接口决定。

自定义 API 使用 OpenAI 兼容的 `multipart/form-data` 转写格式：

```text
POST <接口地址>
file=<录音文件>
model=<模型名称，可选>
language=en
```

接口需要返回 JSON，网站会读取 `text`、`transcript`、`result.text` 或
`data.text`；也支持直接返回纯文本。接口必须允许浏览器跨域访问（CORS），
否则静态网站无法直接调用。API 地址、模型和 Key 只保存在当前浏览器的
`localStorage` 中，并直接发送到所填接口，不会经过本站服务器。

情景对话使用本地脚本和关键词覆盖评分，不依赖服务器、LLM 或付费接口。
用户可以选择浏览器免费识别、填写自己的 OpenAI 兼容转写接口，或关闭识别；
关闭识别后仍可直接输入回答。练习记录只保存在当前浏览器，不会跨设备同步。
百分比表示关键信息覆盖情况，不是发音、口音或语法分数；教练建议会根据本轮
已覆盖内容和遗漏重点在浏览器本地生成。

## 自由对话

自由对话有三种 AI 来源，可在右侧“对话服务”里随时切换：

- `本地免费陪练`：不需要账号和 Key，浏览器本地生成英文追问、中文翻译、
  规则式纠错和雅思练习建议。它是练习辅助，不是完整的大模型对话。
- `自定义 Chat API`：填写任意 OpenAI 兼容的 `chat/completions` 接口后，
  由该接口生成英文回复、中文翻译和纠错内容。费用由你自己的接口账户结算。
- `关闭自动回复`：只记录你写下的英文，不生成回复。

自由对话会保留最近若干轮上下文，英文回复下方固定显示中文翻译，并给出
语法、词汇、表达三个方向的纠错和一条雅思口语练习建议。美音朗读使用浏览器
本地语音合成，默认开启，可以随时关闭。练习建议只作为备考参考，不代表官方
雅思分数。

自定义 Chat API 的 API Key 只保存在当前浏览器的 `localStorage`，随请求直接
发送到所填接口，不经过本站服务器；接口需要允许浏览器跨域访问（CORS）。
调用失败时，网站会自动回到本地免费陪练，并给出提示。

Chat API 的模型名称支持直接输入，也可从 `v4flash`、`v4pro`、`gpt-4o-mini`
等预设项中选择。不同服务商对模型名称和接口格式的要求可能不同，请以服务商
文档为准。

## 登录配置

Vercel 项目需要设置以下 Production 环境变量：

- `APP_USERNAME`
- `APP_PASSWORD`
- `SESSION_SECRET`（至少 32 字节随机字符串）

登录接口位于 `api/auth.js`，使用签名 HttpOnly Cookie 保存会话，不需要额外数据库。

口语练习的交互思路参考了 MIT 许可的
[SpeakHub](https://github.com/yin-yizhen/SpeakHub)。

情景对话与口语练习结构还参考了 MIT 许可的
[spoken](https://github.com/EthanLyu30/spoken)（Copyright 2026 Xiaoyang
Lyu）。

口语教练反馈的分级、轻纠错和单任务练习思路参考了 MIT 许可的
[english-speaking-coach](https://github.com/luyou666/english-speaking-coach)。

自由对话的雅思口语题库结构和练习提示参考了 MIT 许可的
[IELTS Prep](https://github.com/Luxshan2000/ielts-prep)。

自由对话的“英文回复 + 中文翻译 + 每轮纠错”交互参考了 MIT 许可的
[EchoMentor](https://github.com/anticipate218/EchoMentor)。

界面的细分割线、不对称卡片和编号视觉语言参考了 Apache-2.0 许可的
[webtemplate](https://github.com/huangshiyu13/webtemplate)。
